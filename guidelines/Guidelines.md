# Pogot Studio — Studio Color Fields

## Aesthetic
Swiss-inflected, warm-technical. Asymmetric color fields carry the page structure; content lives in defined zones, never floating.

## Palette
| Token | Value | Use |
|---|---|---|
| Powder blue | `#DDE7F2` | Primary background field, large sections |
| Warm white | `#FAF8F3` | Content regions, cards, body field |
| Ink navy | `#18263F` | All body text, headings, navigation |
| Burnt orange | `#D9613E` | CTAs, links, emphasis marks — used once per section |

## Typography
- **Headlines:** Barlow Condensed SemiBold — expressive, technical weight without shouting
- **Body / UI:** Source Sans 3 Regular/SemiBold — open, readable, zero-pretension

Sentence case throughout. No all-caps. Scale: 12px labels → 16px body → 24px subheads → 40–64px display.

## Structure
- Asymmetric two-field layout: blue field (headline + nav or hero copy) offset against warm-white field (content, form, imagery)
- 6px radii on interactive elements only (buttons, inputs)
- No gradients, no diffuse shadows
- Hairline borders `#18263F` at 10–15% opacity for internal structure
- Responsive: fields stack vertically at < 1000px

## Imagery
Unsplash: close-up electronics, PCB boards, embedded hardware. Desaturated or natural tone — no lifestyle.
